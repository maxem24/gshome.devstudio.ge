# CRM-альфа — план реализации

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Клиенты, объекты в работе, сделки, показы, задачи, колокольчик, журнал действий, лента и отчёт руководителя — альфа для показа руководителю агентства на проде, с демо-данными.

**Architecture:** Бизнес-правила — в сервисах `App\Crm\*` (без Filament), права — только через `OrgAccess` (новый `OrgAccess::canActFor`). Filament-экраны тонкие: вызывают сервисы. Журнал — `spatie/laravel-activitylog`, все записи пишет `App\Crm\Journal`. «Ничего не удаляется» — `SoftDeletes` на новых моделях; «В архив» = `delete()`, владелец с `show_archived` видит `withTrashed()`.

**Tech Stack:** PHP 8.5, Laravel 13, Filament 5, PostgreSQL 17, PHPUnit 12, `spatie/laravel-activitylog` ^4.

**Spec:** `docs/superpowers/specs/2026-10-25-crm-alpha-design.md`. Фон — `docs/GSHome/10_Модули_системы.md`.

## Global Constraints

- Всё в Docker: `docker compose exec app …`; composer — только в контейнере; тесты — только `docker compose run --rm test php artisan test --filter=<Имя>`; полный сьют — один раз в конце.
- После каждой задачи: `docker compose exec app composer analyse` — 0 ошибок, без baseline; `docker compose exec app vendor/bin/pint --dirty`.
- Тесты не ходят в сеть — объявления только через `Tests\Support\RealEstateFake`.
- Права «кто что видит и за кого действует» — только `OrgAccess` (`visibleUsers`, `directions`, новый `canActFor`). Ресурсы и политики своих правил не придумывают.
- Ничего не удаляется: на новых моделях `SoftDeletes`, физического удаления в коде нет. Исключение — `saved_listings` (не трогаем).
- Каждое действие человека пишется через `App\Crm\Journal` — не `activity()` напрямую.
- Время — `Asia/Tbilisi` для ввода и напоминаний (`config('crm.timezone')`); в базе — `timestamptz`.
- Подписи — в `lang/{ru,en,ka}/gshome.php`, ключи `crm.*`; грузинский — машинный перевод.
- Имя и телефон клиента не попадают в ленту.
- Ветка `feat/crm-alpha`. Коммиты заканчиваются строкой `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.

## Review Focus

1. **Гонка за объект** — два агента одновременно жмут «Взять в работу» по копиям одной группы: одно закрепление, второй получает «уже в работе», без 500. Тест — Task 4 (`test_second_take_of_same_cluster_fails_even_bypassing_service` — вставка мимо сервиса падает на индексе).
2. **Подделанный id в действии** — агент вызывает действие сделки/показа/задачи чужого агента (Livewire `callAction` с чужим id): 403/404, в базе без изменений. Тесты — Task 5, Task 9c.
3. **Номер в другом виде** — `555 12 34 56`, `0555123456`, `+995555123456` — один и тот же клиент. Тест — Task 2.
4. **Объявление недоступно в API** — «Мои объекты» и карточка сделки с пропавшим объявлением открываются, строка «объявление недоступно». Тест — Task 9b.
5. **Архив скрывает, но не теряет** — архивный клиент не находится поиском по телефону у агента, но номер всё равно занят (нельзя завести второго с тем же номером); у владельца с `show_archived` он виден. Тест — Task 2, Task 9a.
