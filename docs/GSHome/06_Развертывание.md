# Развёртывание у нового разработчика

Цель — за 15–20 минут поднять GS Home локально: рабочая панель, база с демо-структурой,
зелёные тесты. Подробности среды — [[03_Среда_разработки]], тесты — [[04_Тестирование_и_анализ]].

## Что нужно заранее

| что | зачем |
|---|---|
| macOS (Apple Silicon или Intel) или Linux | |
| **OrbStack** — https://orbstack.dev | Docker и домены `*.local` с HTTPS. Docker Desktop не подходит без доработок: домен `gshome.local` и HTTPS раздаёт именно OrbStack, а nginx в проекте рассчитан на HTTPS |
| git и SSH-доступ к приватному репозиторию `maxem24/gshome.devstudio.ge` | доступ выдаёт владелец репозитория |
| PhpStorm (желательно) | инспекции и база через IDE — см. `CLAUDE.md` |
| пакет передачи от коллеги | дамп базы `gshome-db-YYYY-MM-DD.sql.gz` и папка `bin/` |

PHP, Composer, Node и PostgreSQL на машину ставить **не нужно** — всё работает в контейнерах.

## Шаги

### 1. Код и окружение

```bash
git clone git@github.com:maxem24/gshome.devstudio.ge.git gshome
cd gshome
cp .env.example .env
```

### 2. Контейнеры

```bash
docker compose up -d --build
```

Первая сборка образа PHP — несколько минут. Поднимаются `app`, `web`, `horizon`, `postgres`,
`redis`, `mailpit`. Если 5433 на машине занят — поменяй левый порт у `postgres` в
`compose.override.yaml` (он в `.gitignore`), это только доступ к базе с хоста.

### 3. Зависимости и ключ

```bash
docker compose exec app composer install
docker compose exec app php artisan key:generate
```

**Composer — только в контейнере.** Composer с хоста (например, из MAMP) поставит пакеты под
другой PHP, и приложение упадёт на `platform_check.php`.

### 4. База — один из двух вариантов

**А. Из дампа коллеги** (те же люди, компании и номера):

```bash
gunzip -c /путь/к/gshome-db-2026-10-09.sql.gz \
  | docker compose exec -T postgres psql -U gshome -d gshome -q -v ON_ERROR_STOP=1
docker compose exec app php artisan migrate
```

`migrate` после заливки догоняет миграции, появившиеся позже даты дампа (если их нет —
«Nothing to migrate»). Сообщения `NOTICE: ... does not exist, skipping` при заливке — норма.

**Б. С нуля:**

```bash
docker compose exec app php artisan migrate
docker compose exec app php artisan gshome:owner          # свой владелец: имя, email, пароль
docker compose exec app php artisan db:seed --class=OrgDemoSeeder   # демо-структура
```

### 5. Фронт и очереди

```bash
docker compose run --rm node sh -c "npm ci && npm run build"
docker compose restart horizon
```

### 6. Оснастка `bin/`

Скрипты `bin/preflight.sh` и `bin/ship.sh` в репозиторий не входят (оснастка рабочего места) —
они в пакете передачи. Скопируй папку `bin/` в корень проекта:

```bash
cp -R /путь/к/пакету/bin ./bin && chmod +x bin/*.sh
bin/preflight.sh
```

Ожидается `ИТОГ: … FAIL 0`. Предупреждение `HTTPS OrbStack: сертификат не доверен` —
открыть https://gshome.local в браузере один раз и согласиться с сертификатом OrbStack
(или в OrbStack: Settings → включить доверие к его корневому сертификату).

### 7. Проверка

```bash
docker compose run --rm test composer test     # все тесты зелёные
```

Открыть https://gshome.local/admin.

| кто | вход |
|---|---|
| владелец из дампа (`max+cl@absoluteweb.com`) | пароль передаётся отдельно, не в документах; или вариант Б — свой владелец |
| демо-люди (вариант А и Б) | email вида `max+cl.vake.owner@absoluteweb.com`, пароль `password` |

Почта из Docker наружу не уходит — смотреть в https://mail.gshome.local.

## Что в дампе

Схема и данные: пользователи, компании, номера, пары обмена, журнал миграций. Без сессий,
кеша и очередей. Данные демонстрационные, реальных людей и контактов нет. Пароли — только
в виде хешей.

Снять новый дамп:

```bash
docker compose exec -T postgres pg_dump -U gshome -d gshome --no-owner --no-acl --clean --if-exists \
  --exclude-table-data=sessions --exclude-table-data=cache --exclude-table-data=cache_locks \
  --exclude-table-data=jobs --exclude-table-data=job_batches --exclude-table-data=failed_jobs \
  | gzip -9 > gshome-db-$(date +%F).sql.gz
```

## Связанный проект

GS Home будет брать объявления из API **Real Estate** (`maxem24/real-estate.devstudio.ge`).
Пока API нет — для работы с оргструктурой он не нужен. Когда понадобится: склонировать его и
поднять по его `docs/`; из контейнера GS Home он доступен как `https://real-estate.local`
(`REAL_ESTATE_API_URL` в `.env`).

## Частые проблемы

| симптом | причина и лечение |
|---|---|
| `platform_check.php`: нужен PHP 8.4 | composer запускали с хоста — `rm -rf vendor` и `docker compose exec app composer install` |
| https://gshome.local не открывается | OrbStack не запущен или стек поднят не из этой папки: `docker compose ps` |
| тесты: «Тесты запущены на базе gshome» | тесты запускают в `app` — только `docker compose run --rm test composer test` |
| тесты: «закешированный конфиг» | `docker compose exec app php artisan config:clear` |
| правки джобы не видны | `docker compose restart horizon` |
