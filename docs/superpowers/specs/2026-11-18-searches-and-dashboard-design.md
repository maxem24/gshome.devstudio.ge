# Мои поиски: удалить, переименовать, закрепить. Живая инфопанель — дизайн

Дата: 18.11.2026. Размер: небольшой проект.

## Зачем

Агент повторяет один и тот же поиск по сайтам пару раз в неделю. Сейчас поиск нельзя назвать
по-человечески, поднять наверх или убрать старый. Инфопанель показывает только быстрый поиск
и три последних поиска. Человек, зайдя утром, не видит, что ему сегодня делать.

## Цели / не-цели

**Цели**
- В «Моих поисках» автор может **удалить** свой поиск, **переименовать** его и **закрепить**. Закреплённые идут первыми.
- На инфопанели — блок **«Закреплённые поиски»** рядом с «Недавними», с кнопкой «Повторить».
- Над быстрым поиском — **приветствие и сводка дня**: «Добрый день, Нино!», тёплая фраза, «у вас 15 квартир
  в работе, 6 клиентов в сделках и 4 задачи» (каждое число — ссылка), затем дела на сегодня.
- Тексты на ka, ru и en.

**Не-цели**
- Расписание автоповтора поиска («каждый вторник»).
- Общие для команды закреплённые поиски.

## Решения

### Поиски (`listing_searches`)
- Новые колонки: `title varchar(80) null`, `pinned_at timestampTz null`.
- Действия только у автора (`user_id = смотрящий`), как у «Повторить». Руководитель чужие поиски видит, но не меняет.
  - **Переименовать** — окно с одним полем. Пусто означает вернуться к автоматическому описанию фильтров. Не длиннее 80 символов.
  - **Закрепить / открепить** — переключатель, `pinned_at = now()` / `null`.
  - **Удалить** — мягкое удаление с подтверждением. Пока поиск идёт (`queued|running`), кнопки нет: опрос сайтов
    ещё пишет в эту запись.
- Строка таблицы: если есть `title`, он идёт крупно, а описание фильтров — мелко под ним. Без названия всё как сейчас.
  Сортировка: `pinned_at DESC NULLS LAST, id DESC`, у закреплённых — значок булавки.
- «Недавние поиски» на инфопанели остаются как есть (3 последних), но показывают `title`, если он есть.
- **«Закреплённые поиски»** на инфопанели: закреплённые поиски смотрящего, до 10, у каждого название или
  описание и кнопка «Повторить». Повтор — тот же код, что в «Моих поисках»: он выносится из страницы в
  общий класс `App\Search\SearchAgain`. Без закреплённых блок не показывается.

### Приветствие и сводка (`App\Crm\DaySummary` + Livewire-блок на инфопанели)
- Время суток — по `config('crm.timezone')` (Тбилиси): 05:00–11:59 «Доброе утро», 12:00–17:59 «Добрый день»,
  остальное «Добрый вечер». Имя — `users.name`.
- Тёплая фраза — одна из 5 в языке, выбирается по дню года (в течение дня одна и та же).
- Сводка (числа — ссылки):
  - квартир в работе — активные `listing_pins` смотрящего → «Мои объекты»;
  - клиентов в сделках — разные `client_id` в открытых сделках смотрящего (`deals.user_id`) → «Сделки»;
  - задач — открытые пункты `Agenda::for($user)` → «Мои задачи».
  Нулевые числа не пишутся. Если всё по нулям — одна фраза «Пока ничего в работе — самое время найти первую квартиру».
- «На сегодня»: из `Agenda::for($user)` — просроченные и те, у которых срок сегодня, по времени, до 5 штук,
  просроченные помечены. Дальше ссылка «Все задачи». Если ничего нет — «На сегодня дел нет».
- Владелец группы без своих объектов видит приветствие и только ненулевые числа.

## Права
- Переименовать, закрепить и удалить может только автор поиска (проверка на сервере, не только скрытая кнопка).
- Сводка считает только своё: собственные объекты, сделки и задачи.

## Что оставлено исполнителю
Вёрстка блоков в стиле «Недавних поисков», набор тёплых фраз (дружелюбно, без пафоса), значок булавки.

## Тесты
- Поиски: автор переименовывает (пусто → `null`), закрепляет (закреплённый первый), удаляет (исчез из таблицы и
  недавних); чужой поиск: действия скрыты и запросом отвечают 403; идущий поиск удалить нельзя.
- Инфопанель: приветствие по часу (08:00 / 13:00 / 21:00 по Тбилиси), сводка с числами и ссылками, нули не пишутся,
  «на сегодня» — только просроченные и сегодняшние, не больше 5; закреплённые поиски видны и «Повторить» запускает поиск.
